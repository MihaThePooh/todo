# Список дел

Личный список задач с разделами, который живёт на своём сервере.
Ставится на телефон как приложение (PWA) и работает без интернета —
записи уходят на сервер, когда связь вернётся.

Никаких зависимостей: сервер написан на стандартной библиотеке
Python, интерфейс — один HTML-файл без сборки и без фреймворков.

## Запуск

```
python3 server.py
```

Откроется на `http://127.0.0.1:8787`. Порт задан в `server.py`.

При первом запуске рядом появится папка `data/` — в ней всё и
хранится, одним файлом `todo.json`. Пусто на старте, это нормально.

## Доступ снаружи

Приложение не спрашивает логин и пароль: вместо них один ключ
доступа. Положи любую длинную строку в файл `token` рядом с
`server.py` — без неё сервер отвечает только на localhost.

Дальше nginx перед ним и сертификат: примеры конфигов лежат в
`deploy/`, там же готовый юнит systemd. В обоих файлах подставь свой
домен и своего пользователя.

## Данные

```
data/todo.json   все дела
token            ключ доступа
```

Оба пути в `.gitignore`. Бэкап — обычная копия папки `data/`.
